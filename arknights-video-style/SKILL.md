# Arknights Video Style（明日方舟动态视频 + UI 风格）

## Overview

本技能提供一套严格对齐《明日方舟》美术风格的**动态视觉与界面**规范，面向宣传 PV、技能演出、剧情过场、动态立绘（Live2D）、界面动效与游戏 UI 的设计与评估。目标是让产出具备统一的"舟味"：克制、冷峻、战术终端感、末世叙事感。

所有量化参数（时长、帧数、镜头占比、缓动、色值、透明度）均可直接套用，无需猜测。

## 核心设计总则

1. **视觉定位**：动画像「末世战争纪录片 + 战术军事宣传片」——冷静、客观、克制，偶尔捕捉令人屏息的瞬间；UI 像「罗德岛战术指挥终端 + 医疗档案系统」
2. **节奏**：遵循"静—动—静"波浪曲线，铺垫 60%–70%、爆发 15%–25%、回落 10%–15%，单镜头 ≥2 秒
3. **色彩**：低饱和冷灰基底 + 1–2 处点睛色，UI 主色罗德岛蓝 ≤15%
4. **质感**：哑光 + 颗粒，冷色调特效、烟尘实体感，UI 45° 切角 + 1px 细边框
5. **字体统一**：思源黑体分级字重，标题字距 -0.03em 至 -0.05em
6. **克制**：动效服务于功能，不做炫技；表情/动作收着表达

## 使用流程

### A. 生成模式
1. **判断品类**：是动画（PV/技能/过场/Live2D）还是界面（UI 设计/动效演示）？复合任务同时读取对应分册
2. **读取分册**：
   - 动画 → `references/animation-style.md`（节奏/镜头/角色动画/特效/转场/声音/Live2D/配方/规格/禁忌）
   - 界面 → `references/ui-style.md`（色彩/字体/布局/组件/图标/动效/配方/交互/数据可视化/禁忌）
3. **执行**：按规范生成，量化参数直接套用（单镜头 ≥2s、固定镜头 40%、动效 150–300ms、45° 切角 8–12px）
4. **自检**：对照对应分册末尾"禁忌清单"逐条检查，命中任何一条即修正

### B. 评估模式（对已有作品打分）
对任意待评估的方舟风格动画/UI，沿以下维度 0–10 分打分，并用**禁忌否决制**（命中对应分册禁忌清单任意一条 → 直接判不合格）：

| 评估维度 | 检查要点（满分 10） |
|---|---|
| 调性还原 | 沉稳、克制、纪实、战术感、末世感是否到位 |
| 节奏剪辑 | 静—动—静曲线、单镜头 ≥2s、快切 ≤全片 10%、固定镜头 40% |
| 运镜与构图 | 固定/慢推为主、平视 70%、三分法、无 360° 旋转/鱼眼 |
| 特效质感 | 冷色调、烟尘实体感、粒子可数、无彩虹高饱和特效 |
| 声音配合 | 低频环境底噪、干脆动作音、克制 BGM、关键留白 |
| 界面规范 | 45° 切角、1px 边框、线性图标、150–300ms 动效、左对齐、无弹性回弹 |

**评估输出**：总分（满分 60）+ 各维度分 + 命中的禁忌项 + 一句话改进建议。

## 快速要点（含关键量化参数）

### 动画 / PV / 动效
- **节奏**：单镜头 ≥2 秒，固定镜头 40%、慢推 25%、横移 15%、慢拉 10%；快切总时长 ≤10%
- **动作**：三段式"蓄力（3–6 帧）→发力（1–2 帧停顿）→跟随（4–8 帧）"；禁止橡皮筋拉伸、漂浮感
- **特效**：冷色调（青/蓝/紫），源石能量光晕 ≤元素 2 倍，爆炸三段式（白闪 1–2 帧→烟团 8–15 帧→余烬 20–40 帧）
- **转场**：黑场淡入淡出（0.3–0.8s）、硬切、烟雾遮挡、扫描线、故障闪切；禁止 PPT 式转场
- **镜头**：平视 70%、微仰 15%、微俯 10%；运镜速度 ≤画面宽度/秒的 15%
- **Live2D**：单循环 8–12 秒，呼吸 ±2–3px、眨眼每 4–8 秒、无感循环衔接
- 详细规范 → `references/animation-style.md`

### UI 界面
- **色彩**：深炭灰 `#1A1C20` 基底 + 中灰 `#2B2D31` 面板，罗德岛蓝 `#3F72AF` 单屏 ≤15%；禁止纯黑大面积背景
- **字体**：思源黑体分级字重，左对齐，标题字距 -0.03em 至 -0.05em，等宽字体 JetBrains Mono 做数据
- **组件**：45° 斜切角（8–12px，左上+右下对角切）、1px 细边框 `#3F4349`、线性图标 1.5px
- **动效**：150–300ms，linear/ease-out，禁止弹性/回弹；页面切换 ease-in-out 200–300ms
- **数据可视化**：图表用罗德岛蓝主系列，网格线 `#2F3238`，禁用 3D/渐变
- 详细规范 → `references/ui-style.md`

## 通用禁忌

- 禁止高饱和平涂卡通风、彩虹渐变、发光描边/霓虹
- 禁止艺术字体、渐变文字、发光文字
- 禁止夸张表情、卖萌姿势、橡皮筋形变、Q 版化
- 禁止华丽特效堆砌、信息过满、无限旋转 loading
- 禁止全程快切、360° 环绕运镜、鱼眼镜头、PPT 式转场
- 禁止纯黑 `#000000` 大面积背景、死黑无细节阴影
