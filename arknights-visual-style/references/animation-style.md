# 动画设计风格详细规范

适用场景：PV/宣传片、游戏内剧情演出、干员技能动画、界面动态演示、动态壁纸/动态立绘（Live2D）、联名宣传片等。

## 1. 核心节奏与镜头

### 1.1 整体节奏
- 偏沉稳舒缓，叙事优先
- 战斗场景也保持克制的战术感：动作干净利落，而非高速炫技
- 单镜头时长不低于 2 秒（快切只允许出现在极端高燃段落，且不超过全片 10%）

### 1.2 镜头语言
- 以固定镜头、慢推镜头、平视微仰镜头为主
- 多用中景、近景（角色上半身、面部特写），少用大俯大仰的夸张透视
- 保留「档案记录式」的客观感：镜头像战场记录设备在观察，而非主观炫技
- 运镜速度：慢推/横移速度控制在每秒画面位移不超过画面宽度 15%

### 1.3 剪辑节奏
- 转场简洁：黑场淡入淡出、烟雾遮挡转场、扫描线过渡、故障闪切
- 禁用翻页、旋转、缩放弹跳等花哨转场

## 2. 画面动效

### 2.1 角色动效
- 常态：呼吸起伏、眨眼、衣物/发丝随风微动（幅度小，周期 3–6 秒）
- 战斗动作：发力瞬间 1–2 帧停顿（打击感），随后少量惯性跟随；动作干脆，不拖泥带水
- 禁用：夸张形变、橡皮筋式拉伸、卡通化夸张表情
- 表情管理：克制、冷峻，情绪靠眼神与微表情（眉毛、嘴角 1–2mm 级变化）

### 2.2 环境动效
- 以静态场景 + 微弱环境动态为主：扬尘、飘雪、灯光明暗闪烁、设备指示灯呼吸
- 环境粒子（尘埃、火花、纸屑）：稀薄克制，透明度低于 30%，粒子数控制在画面可数级别
- 天气系统：慢速循环，不做高频闪烁

### 2.3 特效表现（源石技能、爆炸、枪火）
- 冷色调为主（青、蓝、白、暗紫），光效柔和不刺眼
- 烟雾/烟尘为厚重实体感（体积感、低透明度层叠），而非透明炫光
- 爆炸：先白闪（1–2 帧）→ 实体烟团扩散 → 余烬飘落，总时长 0.8–1.5 秒
- 枪口火光：单帧高亮 + 短拖尾，不放大面积光斑

## 3. UI 与转场动效

### 3.1 UI 入场
- 从画面边缘滑入 + 淡入，或扫描线式逐行显现
- 可搭配 80–120ms 故障花屏效果（终端唤醒、加载完成、高危警告）
- 禁用回弹、弹性缓动、无限循环旋转

### 3.2 转场方式
- 黑场淡入淡出、烟雾遮挡、扫描线过渡、故障闪切
- 转场时长 0.3–0.8 秒

### 3.3 字幕与信息
- 文字逐行出现或硬切出现，无打字机拖影
- 位置固定在底部安全区，字体规范见 ui-style.md（思源黑体，Heavy/Normal 分级）
- 关键信息可用扫描线揭示动画，不用弹跳放大

## 4. 声音设计配合（如涉及）

- 环境音：低频持续（风声、设备嗡鸣、远距离炮声），音量压低
- 动作音：干脆的短促拟音，不夸张
- 源石技能：冷色调音效（玻璃碎裂、晶体共鸣），混响偏大
- BGM：以弦乐、低音铺底为主，少用电子舞曲式快节奏（除非活动主题明确）

## 5. 时长与规格参考

- 宣传 PV：45–90 秒；战斗展示：30–60 秒
- 动态立绘循环：单循环 8–12 秒，循环点无感衔接
- 帧率参考：24fps 电影感或 30fps 游戏感，保持一致不混用

## 6. 动画禁忌清单

- 禁止快速鬼畜剪辑、每秒 3 切以上的花哨拼接
- 禁止弹性形变、橡皮筋拉伸
- 禁止大面积炫光、高饱和彩虹特效
- 禁止萌系夸张表情、Q 版化处理（除非活动题材明确要求）
- 禁止镜头全程抖动、手持摇晃过度
- 禁止转场使用翻页、旋转、3D 翻转等演示文稿式效果
