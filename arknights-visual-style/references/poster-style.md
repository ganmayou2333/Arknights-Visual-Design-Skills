# 海报设计风格详细规范

适用场景：活动宣传图、版本主视觉（KV）、角色立绘/宣传立绘、IP 联名宣传图（如与战地类游戏联动）、周年贺图、周边视觉等。

## 1. 核心调性

「纪实战术宣传海报」质感：兼具角色立绘的精致度与场景的叙事感，气质沉静有张力。画面像一张战场上拍摄的纪实照片，而不是庆典狂欢海报。

气质关键词：沉静、叙事、张力、纪实、末世。

## 2. 构图逻辑

### 2.1 主体
- 角色为视觉核心，采用半身/七分身构图，重心落在上半身
- 动作幅度小、姿态沉稳：持枪瞄准、静默站立、操作终端、望向远方
- 角色占比约 60%–70%，保留完整头部与肩部，避免裁切发顶

### 2.2 背景与景深
- 弱化远景细节，突出环境氛围：废墟、战场、基地、冻土、荒野、移动城市边缘
- 前中后三层景深：远景为地貌/天空，中景为角色，前景加少量战术元素做遮挡（弹壳、纱布、设备碎片、飘浮尘埃、废墟残件）
- 前景遮挡元素低透明度、浅景深，不遮挡角色五官

### 2.3 信息区
- 顶部或底部预留窄幅信息栏（约占画面高度 10%–15%）
- 信息栏放置：主标题、副标题、阵营标识、日期/版本号
- 信息区不挤占角色主体空间，角色重心避开信息栏

### 2.4 联名海报适配（跨 IP 联动）
- 角色保持明日方舟造型与画风不变
- 背景替换为对方 IP 的经典战场场景；前景融入对方标志性道具（钢盔、步枪、防毒面具、旗帜、载具残骸）
- 视觉权重：方舟角色占 6 成、对方场景元素占 4 成，双方辨识度均衡
- 双方标识并列放置于信息栏两端，大小对等

## 3. 色彩运用

### 3.1 统一色调
- 根据主题定主调：战地/战争类联动用军绿 + 土黄 + 冷灰；常规活动用蓝灰 + 暗青；炎国主题用低饱和朱砂红 + 墨色
- 全画面统一在同一色系内，禁止红蓝各半的撞色拼贴

### 3.2 点睛色
- 仅在角色核心标识处保留高饱和亮色：源石结晶、武器指示灯、瞳孔高光、阵营徽记
- 点睛色面积不超过画面的 5%

### 3.3 光影
- 柔和侧光为主，营造体积感
- 暗角压边（四周压暗 10%–20%），中心区域轻微提亮
- 模拟胶片摄影质感，避免卡通赛璐璐式平涂阴影

### 3.4 颗粒与做旧
- 全画面叠加 10%–15% 的细微颗粒噪点
- 边缘可做轻微磨损/划痕，透明度 5% 以内

## 4. 文字与标识规范

- 标题：硬朗无衬线字体（思源黑体 Heavy 或同风格），字重偏粗，可做轻微倾斜（5°–8°），搭配细下划线或斜切分割线
- 副标题：Light 字重，字距放宽
- 标识：阵营 Logo 放左上角或右下角，尺寸小巧（约占画面宽度 8%），透明度 90%
- 文字颜色仅限：白、灰、主色调（对应主题色）三色

## 5. 典型海报配方

### 5.1 版本活动主视觉（例：故事集/危机合约）
- 背景：灰蓝冷调战场/遗迹，厚重云层压顶
- 主体：核心干员半身像，静默姿态，视线望向画面外
- 前景：飘浮尘埃 + 战术道具残件
- 信息栏：顶部阵营徽记，底部活动标题 + 日期

### 5.2 战地联名宣传图
- 背景：一战风格战场（堑壕、铁丝网、硝烟、远炮火）
- 主体：阿米娅等方舟干员持枪瞄准/举枪射击，军装化战术细节
- 前景：钢盔、步枪剪影、飘散硝烟
- HUD 元素：可叠加轻量战术终端框（字体规范见 ui-style.md），透明度 20% 以内
- 信息栏：左"ARTHNIGHTS"、右联名方标识，中间主题语

### 5.3 角色立绘/宣传立绘
- 背景：单色渐变 + 阵营暗纹（非场景）
- 主体：角色 90% 占比，全身或七分，姿态沉稳
- 光效：柔和顶侧光，源石/武器处保留点睛亮色

## 6. 海报禁忌清单

- 禁止高饱和平涂卡通风
- 禁止夸张透视、鱼眼镜头感
- 禁止华丽特效堆砌（过多光晕、粒子、描边）
- 禁止文字信息过多、文案挤占画面
- 禁止艺术字体、渐变文字、发光文字
- 禁止让角色做夸张笑脸、卖萌姿势（除非活动题材明确要求）
