# UI 设计风格详细规范

适用场景：主界面、干员档案页、技能面板、作战界面、招募/抽卡界面、活动页面、设置页等任何明日方舟风格的界面设计。

## 1. 核心基调

模拟「末日作战指挥终端 / 医疗档案系统」的观感。整体走极简工业档案风：信息层级清晰、功能性优先、无冗余装饰。界面像一套运转中的战术操作系统，而不是游戏商城或社交 App。

气质关键词：克制、冷峻、档案感、终端感、末世科技。

## 2. 色彩规范

### 2.1 背景与面板
- 主底色：深炭灰 `#1A1C20`（禁止纯黑 `#000000`）
- 次级面板：中灰 `#2B2D31`
- 三级浮层/卡片：`#34373D`
- 面板与面板之间用细线分割，禁止大面积色块拼贴

### 2.2 主色调
- 罗德岛标准蓝 `#3F72AF`：核心标识、选中状态、重要信息高亮
- 使用规则：单屏内主色调使用面积不超过 15%，其余靠灰阶层级表达

### 2.3 功能色（语义色）
- 成功/增益：荧光青 `#56B6C9`
- 警告/损耗/物资：暗橙 `#E08E45`
- 危险/负面/敌方：暗红 `#B84A4A`
- 禁用饱和度极高的纯红/纯绿/纯黄

### 2.4 文字色
- 一级文字：纯白 `#FFFFFF`（标题、数值、干员名）
- 二级文字：浅灰 `#C9CDD4`（正文说明）
- 辅助文字：深灰 `#8A8F98`（注释、时间戳、次要标签）
- 禁用文字使用彩色，除非该文字本身承担语义色职责

## 3. 排版规范

### 3.1 字体
- 全链路使用思源黑体（Source Han Sans）系列
- 标题/干员代号：字重 Heavy（900）
- 正文：字重 Normal（400）
- 注释/角标：字重 Light（300）
- 禁用衬线字体、手写体、艺术字

### 3.2 字距与行高
- 标题：字间距 -50（收紧，产生工业铭牌感）
- 正文：字间距默认，行高 1.4–1.6
- 大标题可加 1px 下划线或斜切分割线点缀，不额外加粗描边

### 3.3 对齐与间距
- 以左对齐为核心对齐方式；数据类信息（数值、时间）可右对齐；禁用居中堆砌排版
- 模块间距保持充足呼吸空间，信息密度宁可低不可满
- 同类元素间距一致，形成网格秩序

## 4. 布局与组件

### 4.1 布局
- 模块化卡片布局，卡片四角做 45° 斜切处理（切角约 8–12px），拒绝圆润圆角
- 干员档案采用左右结构：左侧立绘/信息，右侧详情数据
- 界面边缘保留安全边距，重要操作按钮放右下角或底部

### 4.2 边框与分割
- 1px 细实线边框（`#3F4349` 左右）
- 禁用双层粗边框、发光边框、渐变描边
- 列表用 1px 细分隔线，线色 `#2F3238`

### 4.3 图标
- 线性简约风格，1.5px 线宽
- 技能图标：外框颜色对应功能色（增益=青、损耗=橙、危险=红），内部图形以辨识度优先
- 图标不添加投影和渐变

### 4.4 背景纹理
- 面板底层叠加极淡噪点纹理（透明度 3%–5%）
- 主界面可叠加阵营暗纹（罗德岛十字纹、阵营徽记），透明度 5%–10%
- 暗纹位置固定于四角或顶部横幅，不干扰信息阅读

## 5. UI 动效基础

- 状态切换：硬切或 150ms 淡入淡出
- 可搭配极短故障闪烁（80–120ms）用于加载、终端唤醒、高危警告
- 数字跳动采用「机械翻转」效果，禁用弹性缓动
- 禁用回弹、弹跳、无限旋转等卡通感动效

## 6. 典型界面配方

### 6.1 干员档案页
- 背景：深炭灰 + 干员阵营暗纹
- 左侧：干员立绘（低饱和背景）
- 右侧：代号（Heavy 字重）→ 星级/阵营标签 → 档案正文（Normal）→ 属性数值（右对齐）
- 技能图标：按增益/损耗/危险三色分类排放

### 6.2 作战/关卡界面
- 顶部：作战代号 + 关卡编号（右对齐时间）
- 中部：战场区域（留黑，不堆 UI）
- 底部：部署栏 + 费用/行动点（荧光青高亮可用状态）
- 敌人信息用暗红语义色

### 6.3 招募界面
- 中央：干员剪影/立绘
- 四角：阵营徽记（透明度 10%）
- 确认按钮：主色调蓝底白字，斜切角

## 7. UI 禁忌清单

- 禁止圆润圆角卡片（除极小的标签 chip）
- 禁止彩虹渐变、大面积渐变背景
- 禁止发光边框、霓虹描边
- 禁止卡通装饰元素、拟物化 3D 按钮
- 禁止高饱和彩色背景（背景只能灰阶 + 极淡暗纹）
- 禁止居中堆砌、信息过满
