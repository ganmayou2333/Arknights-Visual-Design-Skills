## 简介

本技能提供一套精简、可直接套用的《明日方舟》视觉规范，目标是让产出具备统一的"舟味"识别度：克制、冷峻、战术终端感、末世叙事感。适合快速查阅与轻量集成——无需加载完整手册即可获得关键参数。


## 安装教程

### 方式一：手动安装

#### 步骤 1：获取技能文件

- **如果从 GitHub 下载：** 点击仓库主页的 `Code` 按钮 → `Download ZIP`，下载后解压到本地。
- **如果使用 Git 克隆：**
  ```bash
  git clone https://github.com/ganmayou2333/Arknights-Visual-Design-Skills.git
  ```

#### 步骤 2：定位技能目录

找到你的 AI 代理（Agent）的技能安装目录。常见位置包括：

| 运行环境 | 典型路径 |
|---------|---------|
| 豆包 / Super Doubao | `~/.super_doubao/super-doubao-runtime/workspace/.user_skills/` |
| GitHub Copilot | `~/.codex/skills/` |
| Claude / 其他 Agent | `~/.agents/skills/` |
| 自定义配置 | 你在 AI 代理设置中指定的技能根目录 |

#### 步骤 3：复制技能文件夹

将整个 `arknights-visual-style/` 文件夹复制到技能目录中：

```bash
# Linux / macOS
cp -r arknights-visual-style ~/.super_doubao/super-doubao-runtime/workspace/.user_skills/

# Windows (PowerShell)
Copy-Item -Recurse .\arknights-visual-style "$env:USERPROFILE\.super_doubao\super-doubao-runtime\workspace\.user_skills\"
```

#### 步骤 4：验证文件结构

确保复制后的目录结构完整：

```
arknights-visual-style/
├── SKILL.md
├── README.md
├── readme_cn.md
├── LICENSE
└── references/
    ├── ui-style.md
    ├── poster-style.md
    └── animation-style.md
```

#### 步骤 5：重启/重载 AI 代理

重启你的 AI 代理会话，或触发技能目录重新扫描，使代理识别新安装的技能。

#### 步骤 6：测试安装

向 AI 代理发送测试指令，例如：
- "帮我设计一个明日方舟风格的干员档案界面"
- "生成一张明日方舟风格的活动主视觉海报"
- "明日方舟风格的 PV 动画有什么规范？"

如果代理自动加载了本技能并按照规范回答，说明安装成功。

## 使用方法

安装完成后，当用户请求匹配技能的触发描述时，技能会自动激活。代理将：

1. **判断品类** — 确定任务属于 UI、海报还是动画（复合任务同时加载多个参考）
2. **读取对应分册** — 仅加载相关参考文件
3. **套用量化参数** — 直接使用色值、字体规范、间距、时长等数值
4. **对照禁忌自检** — 检查是否存在禁忌元素（圆角、彩虹渐变、弹性动效等）

### 触发示例

- "设计一个明日方舟风格的主界面 UI"

- "把这个 App 界面改成明日方舟风格"
- "舟味海报怎么设计？"

## 设计哲学

所有明日方舟视觉设计的核心比喻：**想象你是一名随军纪录片摄影师，在泰拉大陆的战场上记录一切。** 你不修饰、不煽情，只是冷静地拍摄。偶尔，一个瞬间让你屏住呼吸。

这转化为五条通用原则：

1. **克制** — 低饱和暗基底，仅 1–2 处点睛色，绝不花哨
2. **冷峻** — 冷灰色调、硬朗几何、无柔软圆角
3. **战术终端感** — 每个元素都像罗德岛指挥终端的一部分
4. **末世叙事感** — 废墟、沙尘、做旧纹理、沉重氛围
5. **功能优先于装饰** — 元素无信息功能则删除

## 快速参考表

| 元素 | 规范值 |
|------|--------|
| 主背景色 | `#1A1C20`（深炭灰，禁止纯黑） |
| 主色调 | `#3F72AF`（罗德岛蓝，单屏 ≤15%） |
| 成功/增益色 | `#56B6C9`（荧光青） |
| 警告色 | `#E08E45`（暗橙） |
| 危险色 | `#B84A4A`（暗红） |
| 主字体 | 思源黑体（Heavy / Normal / Light） |
| 卡片切角 | 45° 斜切（左上+右下对角） |
| 边框 | 1px 实线，`#3F4349` |
| 图标 | 线性风格，1.5px 线宽 |
| UI 动效时长 | 150–300ms，linear / ease-out |
| 海报颗粒 | 10%–15% 单色噪点 |
| 海报暗角 | 10%–20% 边缘压暗 |
| 动画单镜头 | ≥2 秒（快切 ≤10%） |
| 战斗动作 | 蓄力 → 1–2 帧停顿 → 跟随 |
| 转场方式 | 黑场淡入淡出 / 烟雾 / 扫描线 / 故障闪切 |
