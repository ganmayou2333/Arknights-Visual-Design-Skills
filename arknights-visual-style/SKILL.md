# Arknights Visual Style（明日方舟风格视觉设计）

## Overview

本技能提供一套严格对齐《明日方舟》官方美术调性的视觉规范，供生成 UI、海报、动画三类视觉产物时直接套用。目标是让产出具备统一的"舟味"识别度：克制、冷峻、战术终端感、末世叙事感。

## 何时使用

- 用户要求设计/生成明日方舟风格或"舟味"的界面、海报、立绘、宣传图、PV、动效
- 用户要求把现有视觉（如某游戏的联名宣传图、App 界面、宣传片）改造成明日方舟风格
- 用户仅提供模糊风格词（"像明日方舟""方舟美术风格"）时，由本技能提供完整可执行规范

## 核心设计总则（所有品类通用）

1. **色彩底层逻辑**：以低饱和冷灰/深暗基底为画面主调，仅用 1–2 处高饱和亮色点睛，拒绝大面积艳丽色彩
2. **世界观基调**：近未来末世工业风，融合医疗科技、战术军事、地域人文，气质克制、内敛、沉重
3. **质感统一标准**：全品类哑光 + 轻微颗粒/做旧质感，规避高光亮面与卡通赛璐璐平涂
4. **字体统一**：全链路思源黑体，标题 Heavy、正文 Normal、注释 Light
5. **装饰克制**：任何装饰元素都必须是功能性的（信息、标识、战术元素），不为装饰而装饰

## 使用流程

1. **判断品类**：明确任务是 UI、海报、动画中的哪一类；复合任务（如联名宣传图 + HUD）同时读取对应分册
2. **读取分册**：按品类读取对应的 references 文件，严格按其数值规范执行：
   - UI 界面 → 读取 `references/ui-style.md`（色值、字体、组件、动效全量规范）
   - 海报/立绘/联名图 → 读取 `references/poster-style.md`（构图、色调、光影、文字规范）
   - 动画/PV/动效 → 读取 `references/animation-style.md`（节奏、镜头、特效、转场规范）
3. **执行**：按分册规范生成或改造，量化参数（色值、字重、透明度、时长）直接套用
4. **自检**：对照"禁忌清单"逐条检查，命中任何一条即修正

## 三大品类快速要点

### UI 界面
- 深炭灰 `#1A1C20` 基底 + 中灰 `#2B2D31` 面板，主色罗德岛蓝 `#3F72AF`
- 45° 斜切卡片角、1px 细边框、线性图标、暗纹底纹（透明度 5%–10%）
- 左对齐排版，思源黑体分级字重，标题字距 -50
- 详细规范 → `references/ui-style.md`

### 海报 / 立绘 / 联名宣传图
- 纪实战术海报质感：角色占 6–7 成、姿态沉稳、前中后三层景深
- 统一色系 + 暗角压边 + 10%–15% 颗粒噪点；点睛亮色不超过画面 5%
- 联名适配：角色保持方舟造型，背景/前景融入对方 IP 标志物（如战地系：钢盔、堑壕、硝烟、防毒面具）
- 详细规范 → `references/poster-style.md`

### 动画 / PV / 动效
- 沉稳节奏：单镜头 ≥2 秒，慢推/固定镜头为主，克制战术感
- 战斗动作 1–2 帧发力停顿；特效冷色调、烟尘实体感
- 转场只用黑场淡入淡出、扫描线、故障闪切
- 详细规范 → `references/animation-style.md`

## 通用禁忌（三品类共享）

- 禁止高饱和平涂卡通风、彩虹渐变、发光描边
- 禁止艺术字体、渐变文字、发光文字
- 禁止夸张表情、卖萌姿势、橡皮筋形变
- 禁止华丽特效堆砌、信息过满
