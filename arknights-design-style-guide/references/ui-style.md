## 1. 核心设计哲学

### 1.1 世界观映射

明日方舟的 UI 本质上是一套「末日作战指挥终端 + 医疗档案管理系统」的界面语言。每一个界面元素都应该让用户感觉自己正在操作一台罗德岛陆行舰上的战术指挥终端，而不是在玩一款色彩缤纷的休闲游戏。

设计时始终自问：**这个元素在罗德岛的终端系统里承担什么功能？** 如果答案是"纯装饰"，就应该删除或改造为功能性元素。

### 1.2 气质关键词

| 关键词 | 含义 | 设计体现 |
|--------|------|----------|
| 克制 | 不张扬、不喧哗 | 低饱和配色、克制的动效、充足留白 |
| 冷峻 | 冷静、理性、距离感 | 冷灰色调、硬朗几何、无圆润感 |
| 档案感 | 像查阅机密军事档案 | 编号系统、时间戳、分类标签、细线分割 |
| 终端感 | 像操作战术操作系统 | 扫描线、故障闪烁、机械字体、状态指示灯 |
| 末世科技 | 近未来废土工业风 | 做旧纹理、磨损边缘、工业铭牌式排版 |
| 功能性 | 一切元素皆有 purpose | 装饰即信息，信息即装饰 |

### 1.3 设计原则层级

1. **信息可读性优先** — 任何视觉效果不得影响文字和数据的清晰阅读
2. **功能识别性第二** — 用户必须一眼分辨可点击/不可点击/选中/禁用状态
3. **风格统一性第三** — 在满足前两条的前提下，严格遵循方舟视觉调性
4. **装饰性最后** — 仅在前三条都满足时，才允许添加氛围性装饰

## 2. 色彩系统

### 2.1 背景层级（灰阶系统）

明日方舟的背景不是纯黑，而是一套精心调校的深灰阶梯，通过灰度差异营造空间纵深。

| 层级 | 色值 | 用途 | 透明度规则 |
|------|------|------|-----------|
| L0 基底 | `#1A1C20` | 页面最底层背景、全屏底色 | 100% 不透明 |
| L1 面板 | `#2B2D31` | 主内容面板、卡片容器 | 100% 或 95%（叠加时） |
| L2 浮层 | `#34373D` | 弹出层、二级卡片、下拉菜单 | 98%–100% |
| L3 悬停 | `#3D4047` | 鼠标悬停态、列表高亮行 | 100% |
| 分割线 | `#2F3238` | 列表分隔、区域边界 | 100% |
| 边框线 | `#3F4349` | 卡片外框、输入框边框 | 100% |

**关键规则：**
- 禁止使用纯黑 `#000000` 作为任何大面积背景
- 相邻面板之间至少差一个灰阶层级，禁止同色面板直接拼接
- 面板叠加时，上层面板永远比下层亮（灰度值更高）

### 2.2 主色调（品牌色）

| 色名 | 色值 | 用途 | 面积限制 |
|------|------|------|---------|
| 罗德岛蓝（标准） | `#3F72AF` | 核心标识、选中态、主按钮、重要高亮 | 单屏 ≤15% |
| 罗德岛蓝（深） | `#2C5480` | 按钮按下态、选中背景 | — |
| 罗德岛蓝（浅） | `#5A8CC9` | 链接文字、图标高亮 | — |
| 罗德岛蓝（极浅） | `#A8C4E0` | 图表数据系列、进度条 | — |

**使用规则：**
- 主色调是「点睛色」，不是「铺底色」
- 一个界面中主色调的出现应聚焦在 1–2 个核心交互点
- 禁止用主色调做大面积背景填充（除加载页/品牌页外）

### 2.3 语义功能色

功能色用于传达状态信息，必须保持低饱和度，避免与整体冷峻调性冲突。

| 语义 | 色名 | 色值 | 典型用途 |
|------|------|------|---------|
| 成功/增益/可用 | 荧光青 | `#56B6C9` | 治疗量、增益buff、可部署、费用充足 |
| 警告/损耗/物资 | 暗橙 | `#E08E45` | 生命值低、消耗品、倒计时、物资数量 |
| 危险/负面/敌方 | 暗红 | `#B84A4A` | 敌人信息、伤害数字、失败状态、删除确认 |
| 稀有/高级 | 暗金 | `#C9A84C` | 高星干员标识、稀有物品、特殊标签 |
| 信息/中性 | 钢蓝灰 | `#6B7B8D` | 提示信息、次要状态、说明标签 |

**禁用：**
- 禁止使用高饱和纯红 `#FF0000`、纯绿 `#00FF00`、纯黄 `#FFFF00`
- 禁止功能色之间大面积混用（如红绿各半的对比布局）
- 功能色仅用于状态标识，不用于装饰性图形

### 2.4 文字色阶

| 层级 | 色值 | 用途 | 对比度要求 |
|------|------|------|-----------|
| 一级文字 | `#FFFFFF` | 标题、干员代号、核心数值、按钮文字 | ≥ 12:1 |
| 二级文字 | `#C9CDD4` | 正文说明、描述文本、列表内容 | ≥ 7:1 |
| 三级文字 | `#8A8F98` | 注释、时间戳、次要标签、占位符 | ≥ 4.5:1 |
| 禁用文字 | `#5A5E66` | 不可用状态文字、过期信息 | ≥ 3:1 |

**规则：**
- 文字默认使用灰阶，禁止给普通文字上色
- 只有当文字本身承担语义功能时才使用功能色（如"伤害 +200"用暗红）
- 同一段落内文字色不超过 2 种（不含语义高亮）

### 2.5 渐变使用规范

明日方舟 UI 中渐变极为克制，仅在特定场景使用：

| 场景 | 渐变方向 | 色值组合 | 透明度 |
|------|---------|---------|--------|
| 面板顶部高光 | 上→下 | `#34373D` → `#2B2D31` | 100% |
| 按钮悬停 | 上→下 | `#4A7BB8` → `#3F72AF` | 100% |
| 信息栏遮罩 | 下→上 | `#1A1C20`(0%) → `#1A1C20`(80%) | 渐变透明 |
| 暗角 | 中心→边缘 | 透明 → `#000000`(30%) | 径向渐变 |

**禁止：**
- 禁止彩虹渐变、多色渐变
- 禁止用渐变做大面积背景
- 禁止渐变文字（标题文字必须纯色）

## 3. 字体与排版

### 3.1 字体家族

**首选字体：思源黑体（Source Han Sans / Noto Sans CJK）**

| 字重 | 数值 | 用途 |
|------|------|------|
| Heavy | 900 | 页面大标题、干员代号、版本号、品牌名 |
| Bold | 700 | 模块标题、按钮文字、表格表头 |
| Medium | 500 | 二级标题、标签文字、重要数据 |
| Normal/Regular | 400 | 正文、描述、列表内容 |
| Light | 300 | 注释、角标、时间戳、辅助说明 |

**英文/数字专用：**
- 标题英文可使用 `Rajdhani`、`Barlow Condensed` 等窄体工业风字体
- 数据数字推荐使用等宽字体 `JetBrains Mono` 或 `Roboto Mono`，营造终端读数感
- 禁止使用衬线字体（Times、宋体）、手写体、圆体、卡通字体

### 3.2 字号阶梯（基准 16px）

| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Display | 48–72px | 1.1 | Heavy | 全屏标题、版本名、活动名 |
| H1 | 32–40px | 1.2 | Heavy | 页面主标题、干员代号 |
| H2 | 24–28px | 1.3 | Bold | 模块标题、分区标题 |
| H3 | 20px | 1.4 | Medium | 卡片标题、列表组标题 |
| Body-L | 18px | 1.5 | Normal | 重要正文、对话文本 |
| Body | 16px | 1.5 | Normal | 标准正文、说明文字 |
| Body-S | 14px | 1.4 | Normal | 次要正文、表格内容 |
| Caption | 12px | 1.3 | Light | 注释、时间戳、角标 |
| Micro | 10px | 1.2 | Light | 极小标签、状态指示 |

### 3.3 字距与字间距

| 文本类型 | 字距（letter-spacing） | 效果 |
|---------|----------------------|------|
| 大标题/代号 | -50 至 -30（-0.05em 至 -0.03em） | 收紧，工业铭牌感 |
| 模块标题 | -20（-0.02em） | 轻微收紧 |
| 正文 | 0（默认） | 标准可读性 |
| 注释/标签 | +20 至 +50（+0.02em 至 +0.05em） | 放宽，技术标签感 |
| 全大写英文 | +50 至 +100（+0.05em 至 +0.1em） | 军用标识感 |

### 3.4 对齐规则

- **主对齐方式：左对齐** — 所有标题、正文、列表默认左对齐
- **右对齐场景：** 数值数据（攻击力、生命值、费用）、时间戳、页码、金额
- **居中对齐场景：** 仅用于全屏加载页、空状态提示、确认对话框按钮组
- **禁止：** 两端对齐（justify）、居中堆砌的正文段落

### 3.5 文本装饰

- 大标题下方可加 1–2px 细横线（主色调或灰色），长度为标题宽度的 30%–60%
- 重要标签可加斜切角背景块（参考组件规范）
- 禁止文字下划线（链接除外）、删除线（非语义用途）、文字描边、文字阴影（极淡投影除外）
- 禁止文字渐变、发光文字、霓虹文字效果

## 4. 布局与网格系统

### 4.1 基础网格

- **桌面端：** 12 列网格，列间距 16px，页面边距 32px
- **平板端：** 8 列网格，列间距 12px，页面边距 24px
- **移动端：** 4 列网格，列间距 8px，页面边距 16px
- 所有组件必须对齐网格，禁止随意摆放

### 4.2 卡片与切角

明日方舟 UI 最标志性的特征之一是**45° 斜切角**，而非圆角。

| 组件类型 | 切角大小 | 切角位置 |
|---------|---------|---------|
| 大面板/主卡片 | 10–14px | 左上角 + 右下角（对角切） |
| 中卡片/模块 | 8–10px | 左上角单切 或 对角切 |
| 小标签/Chip | 4–6px | 左上角单切 |
| 按钮 | 6–8px | 左上角 + 右下角 |
| 输入框 | 4px | 左上角单切 或 不切（直角） |

**切角实现要点：**
- 切角必须是精确的 45° 直线切割，不是圆弧过渡
- 切角处的边框线应连续，不可断裂
- 切角方向统一：左上角和右下角为一组，右上角和左下角为另一组，同一界面内不混用
- 极小元素（< 32px）可不切角，保持直角

### 4.3 间距系统

采用 4px 基础单位的间距阶梯：

| 级别 | 数值 | 用途 |
|------|------|------|
| xs | 4px | 图标与文字间距、极小内边距 |
| sm | 8px | 紧凑元素间距、标签内边距 |
| md | 16px | 标准内边距、列表项间距 |
| lg | 24px | 模块间距、卡片内边距 |
| xl | 32px | 大区块间距、页面水平边距 |
| 2xl | 48px | 页面分区间距 |
| 3xl | 64px | 全屏页面垂直边距 |

### 4.4 典型布局结构

#### 4.4.1 左右分栏布局（干员档案/详情页）
```
┌─────────────────────────────────────────┐
│  顶部导航栏（高 56px）                     │
├──────────────┬──────────────────────────┤
│              │                          │
│  左侧 40%     │      右侧 60%            │
│  立绘/头像    │      详细数据/文字        │
│              │                          │
│              │                          │
└──────────────┴──────────────────────────┘
```

#### 4.4.2 上下分区布局（作战/主界面）
```
┌─────────────────────────────────────────┐
│  顶部状态栏（作战代号/时间/资源）          │
├─────────────────────────────────────────┤
│                                         │
│         中央主内容区（留黑/战场）          │
│                                         │
├─────────────────────────────────────────┤
│  底部操作栏（部署/技能/行动点）            │
└─────────────────────────────────────────┘
```

#### 4.4.3 网格卡片布局（仓库/干员列表）
```
┌─────────────────────────────────────────┐
│  筛选/排序栏                              │
├──────┬──────┬──────┬──────┬─────────────┤
│ 卡片  │ 卡片  │ 卡片  │ 卡片  │             │
├──────┼──────┼──────┼──────┼─────────────┤

```

## 5. 组件规范

### 5.1 按钮

| 状态 | 背景 | 文字 | 边框 |
|------|------|------|------|
| 默认（主按钮） | `#3F72AF` | `#FFFFFF` Heavy | 无 |
| 悬停 | `#4A7BB8` | `#FFFFFF` | 无 |
| 按下 | `#2C5480` | `#FFFFFF` | 无 |
| 禁用 | `#3A3D43` | `#5A5E66` | 无 |
| 默认（次按钮） | `#2B2D31` | `#C9CDD4` | 1px `#3F4349` |
| 悬停（次按钮） | `#34373D` | `#FFFFFF` | 1px `#4A4E55` |
| 危险按钮 | `#B84A4A` | `#FFFFFF` | 无 |

**按钮规格：**
- 高度：大按钮 48px、中按钮 40px、小按钮 32px
- 内边距：水平 24px（大）、16px（中）、12px（小）
- 切角：左上角 + 右下角 6–8px
- 文字：Bold 字重，全大写时字距 +0.05em
- 图标与文字间距 8px，图标尺寸 16–20px

### 5.2 输入框

- 高度：40px（标准）、32px（紧凑）
- 背景：`#1A1C20`
- 边框：1px `#3F4349`，聚焦时变为 `#3F72AF`
- 文字：`#C9CDD4`，占位符 `#5A5E66`
- 内边距：水平 12px
- 切角：左上角 4px 或直角
- 禁用态：背景 `#222428`，文字 `#5A5E66`

### 5.3 标签/Chip

| 类型 | 背景 | 文字 | 边框 |
|------|------|------|------|
| 阵营标签 | 对应阵营色 15% 透明 | 对应阵营色 | 1px 对应阵营色 30% |
| 职业标签 | `#2B2D31` | `#C9CDD4` | 1px `#3F4349` |
| 稀有度标签 | 暗金 `#C9A84C` 15% | `#C9A84C` | 1px `#C9A84C` 30% |
| 状态标签（增益） | 荧光青 12% | `#56B6C9` | 1px 荧光青 25% |
| 状态标签（负面） | 暗红 12% | `#B84A4A` | 1px 暗红 25% |

- 高度：24–28px
- 内边距：水平 8px
- 切角：左上角 4px
- 文字：12–14px，Medium 字重

### 5.4 列表项

- 高度：48–56px（标准）、40px（紧凑）
- 分隔线：底部 1px `#2F3238`
- 悬停背景：`#34373D`
- 选中背景：`#2C5480` 15% + 左侧 3px 主色调竖线
- 左侧图标/头像：32–40px 见方
- 文字：标题 16px Normal + 副标题 12px Light
- 右侧数值/箭头：右对齐

### 5.5 进度条/血条

- 高度：6–8px（标准）、4px（细）
- 背景：`#1A1C20`，边框 1px `#3F4349`
- 填充色：
  - 生命值：荧光青 `#56B6C9`（高）→ 暗橙 `#E08E45`（中）→ 暗红 `#B84A4A`（低）
  - 经验/加载：罗德岛蓝 `#3F72AF`
  - 技能冷却：钢蓝灰 `#6B7B8D`
- 切角：两端直角或左端 2px 切角
- 数值标注：右侧或居中，12px Light

### 5.6 弹窗/对话框

- 背景：`#2B2D31`，边框 1px `#3F4349`
- 遮罩：`#000000` 70% 透明度
- 切角：左上角 + 右下角 12px
- 标题栏：高 48px，底部 1px 分割线，标题左对齐 Heavy
- 内容区：内边距 24px
- 按钮区：底部右对齐，按钮间距 12px
- 入场动画：从中心缩放 0.95→1.0 + 淡入，时长 200ms

### 5.7 标签页/Tab

- 高度：40px
- 未选中：文字 `#8A8F98`，无背景
- 选中：文字 `#FFFFFF`，底部 2px 主色调线
- 悬停：文字 `#C9CDD4`
- 间距：Tab 之间 24px
- 禁用滑动动画，切换硬切或 150ms 淡入

### 5.8 开关/Toggle

- 尺寸：40×22px
- 关闭：背景 `#3A3D43`，圆点 `#8A8F98`
- 开启：背景 `#3F72AF`，圆点 `#FFFFFF`
- 圆点：18px 直径（注意：这是少数允许圆形的元素）
- 切换动画：200ms 平滑滑动，禁用弹性

## 6. 图标与图形语言

### 6.1 图标风格

- **风格：线性图标（line icon）**，1.5px 标准线宽
- **端点：圆形端点（round cap）**
- **拐角：圆角连接（round join）**，半径 1px
- **尺寸阶梯：** 16px、20px、24px、32px、48px
- **颜色：** 默认 `#C9CDD4`，激活/选中 `#3F72AF`，禁用 `#5A5E66`
- **禁止：** 填充式图标、拟物图标、3D 图标、渐变图标、带投影图标

### 6.2 技能图标

- 外框：菱形或方形切角，边长 48–64px
- 外框颜色：对应功能色（增益=青、损耗=橙、危险=红、中性=灰）
- 内部图形：白色或浅色线性符号，辨识度优先
- 背景：`#1A1C20` 或透明
- 升级/精英化：外框加 1px 暗金边 `#C9A84C`

### 6.3 阵营徽记

- 罗德岛：十字+菱形组合，标准蓝 `#3F72AF`
- 其他阵营：使用各自代表色，但饱和度降低 20%–30%
- 使用场景：左上角品牌位、卡片角标、背景暗纹
- 尺寸：不超过卡片宽度的 12%
- 透明度：实体使用 90%–100%，背景暗纹 5%–10%

### 6.4 几何装饰元素

明日方舟 UI 中允许的功能性几何装饰：

| 元素 | 规格 | 用途 |
|------|------|------|
| 斜切分割线 | 1px，45° 倾角，长 20–40px | 标题旁装饰、分区标识 |
| 角标括号 | L 形，1px 线，边长 8–12px | 面板四角装饰、取景框感 |
| 刻度线 | 1px 竖线，高 4–8px，间距 8px | 数据面板边缘、终端感 |
| 点阵网格 | 2px 圆点，间距 16px，透明度 5% | 背景科技感纹理 |
| 扫描线 | 1px 横线，主色调 30% | 加载/唤醒动画 |

## 7. 背景纹理与装饰

### 7.1 噪点纹理

- 全界面底层叠加细微噪点（noise），透明度 3%–5%
- 噪点类型：高斯噪点，单色（白色或灰色）
- 作用：打破纯数字界面的光滑感，增加末世终端的物理质感
- 禁止：彩色噪点、高透明度噪点（>10%）

### 7.2 阵营暗纹

- 主界面/专题页可叠加阵营徽记或几何暗纹
- 位置：四角、顶部横幅、或居中平铺
- 透明度：5%–10%
- 大小：单个暗纹不超过屏幕宽度的 30%
- 暗纹不得干扰任何文字和交互元素的阅读

### 7.3 网格底纹

- 数据密集型界面（作战、终端）可叠加极淡网格线
- 网格尺寸：32×32px 或 64×64px
- 线条：1px，颜色 `#FFFFFF`，透明度 2%–3%
- 作用：增强"战术雷达/指挥终端"的空间感

### 7.4 磨损与做旧

- 面板边缘可加极淡的磨损效果，透明度 ≤5%
- 形式：边缘不规则暗色、细微划痕、角落锈迹
- 仅限氛围性使用，不得覆盖文字和图标
- 禁止：大面积做旧、高对比度划痕、水渍效果

## 8. UI 动效规范

### 8.1 动效总原则

- **克制：** 动效服务于功能反馈，不为炫技而存在
- **快速：** 绝大多数动效在 150–300ms 内完成
- **硬朗：** 使用线性或轻微缓动，禁止弹性/回弹
- **统一：** 同类交互使用相同动效，形成肌肉记忆

### 8.2 缓动函数

| 场景 | 缓动 | 时长 |
|------|------|------|
| 页面切换 | ease-in-out | 200–300ms |
| 面板展开/收起 | ease-out | 200ms |
| 按钮状态 | linear 或 ease-out | 100–150ms |
| 数字变化 | linear（步进） | 按数值差 |
| 加载/等待 | linear（循环） | 循环 |
| 故障闪烁 | linear（硬切） | 80–120ms |

**禁止缓动：** `elastic`、`bounce`、`back`（回弹类）

### 8.3 页面转场

- 主界面切换：左右滑入（方向对应导航逻辑），时长 250ms，ease-in-out
- 详情页进入：从底部上滑 + 淡入，时长 300ms
- 弹窗：中心缩放 0.95→1.0 + 淡入，时长 200ms
- 下拉面板：从顶部下滑，时长 200ms
- 禁止：3D 翻转、翻页、旋转、立方体转场

### 8.4 组件动效

| 组件 | 动效 | 时长 |
|------|------|------|
| 按钮悬停 | 背景色渐变 | 150ms |
| 按钮按下 | 缩放 0.97 | 80ms |
| 列表项悬停 | 背景色渐变 | 150ms |
| Tab 切换 | 下划线滑动 + 内容淡入 | 200ms |
| 开关切换 | 圆点平滑滑动 | 200ms |
| 进度条 | 线性填充 | 按差值 |
| 数字跳动 | 机械翻牌/步进递增 | 300–500ms |

### 8.5 终端特效（限定场景）

以下特效仅在特定场景使用，不可滥用：

| 特效 | 场景 | 参数 |
|------|------|------|
| 故障闪烁（Glitch） | 加载完成、终端唤醒、高危警告 | 80–120ms，RGB 分离 2–3px |
| 扫描线 | 数据加载、界面初始化 | 1px 横线从上到下，2s 循环 |
| 逐行显现 | 档案读取、剧情文本 | 每行 30–50ms 延迟 |
| 信号干扰 | 通讯中断、敌人出现 | 水平位移 2–4px，持续 200ms |

**使用限制：**
- 故障闪烁单次不超过 200ms，同一界面每分钟不超过 3 次
- 扫描线透明度 ≤20%，不得影响阅读
- 光敏性安全：闪烁频率不得超过 3Hz（每秒 3 次）

## 9. 典型界面配方

### 9.1 主界面（终端首页）

**布局：**
- 顶部：状态栏（资源数值：合成玉/龙门币/理智，右对齐）
- 左侧：导航菜单（竖向图标+文字，选中态左侧蓝线）
- 中央：干员立绘/活动宣传图（低饱和处理）
- 底部：功能入口图标栏（4–6 个）

**配色：**
- 背景 `#1A1C20` + 罗德岛暗纹 8%
- 导航选中 `#3F72AF` 文字 + 左侧 3px 竖线
- 资源数字 `#FFFFFF` Heavy，单位 `#8A8F98` Light

**动效：**
- 立绘轻微呼吸（透明度 95%↔100%，4s 循环）
- 理智回复进度条缓慢填充

### 9.2 干员档案页

**布局：** 左右分栏（左 40% 立绘，右 60% 数据）
- 左侧：立绘（低饱和背景）+ 阵营徽记角标
- 右侧顶部：代号（Heavy 40px）+ 英文名（Light 16px，字距 +0.1em）+ 职业/星级标签
- 右侧中部：属性面板（攻击/防御/生命/法抗，数值右对齐）
- 右侧下部：天赋/技能列表（可展开）+ 档案文本

**配色：**
- 立绘背景：根据阵营定调（罗德岛=蓝灰、整合运动=暗红灰等）
- 属性数值：`#FFFFFF` Heavy，属性名 `#8A8F98`
- 精英化阶段：暗金标签

### 9.3 作战/关卡界面

**布局：** 上中下三区
- 顶部：作战代号（左）+ 关卡编号 + 当前波次（中）+ 暂停/速度（右）
- 中部：战场区域（最大化留黑，UI 不覆盖）
- 底部：部署栏（干员头像横向排列）+ 费用/行动点（荧光青高亮）

**配色：**
- 敌人信息/血条：暗红 `#B84A4A`
- 我方单位/可部署：荧光青 `#56B6C9`
- 费用充足：荧光青；费用不足：暗红闪烁（1Hz）

**HUD 元素：**
- 干员范围预览：虚线框，主色调 50%
- 攻击范围：半透明色块，主色调 15%
- 伤害数字：弹跳出现后上飘消失，暗红/白色

### 9.4 招募界面

**布局：**
- 中央：干员剪影/立绘（聚光灯效果）
- 四角：阵营徽记（透明度 10%）+ 角标括号装饰
- 底部：招募按钮（主色调，斜切角）+ 资源消耗显示

**动效：**
- 招募中：扫描线从上到下循环 + 剪影轻微故障闪烁
- 获得干员：白光闪 1–2 帧 → 立绘渐显 → 信息栏滑入
- 高星干员：额外暗金光效 + 粒子上升（克制，粒子数 <20）

### 9.5 活动专题页

**布局：**
- 顶部 Banner：活动主视觉（参考海报规范）+ 活动标题
- 中部：活动机制说明卡片（2–3 列网格）
- 下部：奖励列表/任务列表
- 侧边：活动倒计时（暗橙，等宽字体）

**配色：**
- 根据活动主题定主色调（如战地联动=军绿、夏日=低饱和青蓝）
- 但背景仍保持灰阶，主色调仅用于强调元素

### 9.6 加载界面

- 全屏 `#1A1C20` 背景
- 中央：罗德岛徽记（静态或缓慢旋转，旋转周期 ≥8s）
- 下方：加载进度条（细，4px）+ 提示文字（12px Light，随机切换游戏小贴士）
- 可选：扫描线全屏缓慢移动
- 禁止：转圈 loading 动画（用进度条或徽记呼吸代替）

## 10. 交互反馈规范

### 10.1 点击反馈

- 所有可点击元素必须有明确的悬停态和按下态
- 悬停：背景提亮一个灰阶层级 或 文字变白
- 按下：缩放 0.97 或 背景压暗
- 不可点击元素：无任何状态变化，鼠标为默认箭头

### 10.2 状态反馈

| 状态 | 视觉反馈 | 音效（如涉及） |
|------|---------|--------------|
| 成功 | 荧光青图标 + 文字，可选 1px 外框闪 | 短促清脆"嘀"声 |
| 失败/错误 | 暗红文字 + 输入框暗红边框 + 轻微抖动（±2px，200ms） | 低沉"嗡"声 |
| 警告 | 暗橙文字 + 图标闪烁（1Hz，持续 3s） | 中等频率"嘀嘀"声 |
| 加载中 | 进度条或骨架屏，禁用交互 | 无或低频环境音 |
| 空状态 | 居中图标（线性，灰色 50%）+ 说明文字 | 无 |

### 10.3 数据更新反馈

- 数值变化：旧数字淡出/上移 → 新数字淡入/下移，时长 200ms
- 或使用机械翻牌效果（等宽字体，数字逐位滚动）
- 资源增加：绿色（荧光青）短暂闪烁 + 数字跳动
- 资源减少：暗红短暂闪烁 + 数字跳动

## 11. 数据可视化规范

### 11.1 图表配色

- 主数据系列：罗德岛蓝 `#3F72AF`
- 对比系列：荧光青 `#56B6C9`、暗橙 `#E08E45`、钢蓝灰 `#6B7B8D`
- 背景：透明或 `#1A1C20`
- 网格线：`#2F3238`，1px
- 坐标轴文字：`#8A8F98`，12px Light

### 11.2 图表类型选择

| 数据类型 | 推荐图表 | 禁用图表 |
|---------|---------|---------|
| 趋势变化 | 折线图（细线，无数据点标记） | 3D 柱状图 |
| 占比分布 | 横向条形图 或 环形图（中空 ≥50%） | 饼图（3D/爆炸） |
| 对比排名 | 横向条形图（左标签右数值） | 雷达图（除非能力值） |
| 能力值 | 雷达图（5–6 轴，填充 15%） | 花哨仪表盘 |
| 进度 | 进度条（水平） | 环形进度（除非空间受限） |

### 11.3 干员能力雷达图

- 5–6 个维度（攻击、防御、生命、法抗、费用、再部署等）
- 网格：3 层多边形，线条 `#3F4349`
- 数据填充：主色调 15% 透明度，边线主色调 100%
- 轴标签：12px Light，位于轴端点外侧
- 禁止：3D 效果、渐变填充、动画旋转

## 12. UI 禁忌清单

### 12.1 色彩禁忌
- 禁止纯黑 `#000000` 大面积背景
- 禁止高饱和彩色背景（背景只能灰阶 + 极淡暗纹）
- 禁止彩虹渐变、多色渐变
- 禁止发光边框、霓虹描边、外发光效果
- 禁止文字使用彩色（语义色除外）
- 禁止渐变文字、发光文字

### 12.2 形状禁忌
- 禁止大圆角卡片（圆角 > 8px 的元素都需谨慎）
- 禁止圆形头像/卡片（阵营徽记、开关圆点等功能性圆形除外）
- 禁止气泡式对话框、云朵形按钮
- 禁止不规则有机形状

### 12.3 排版禁忌
- 禁止居中堆砌的正文排版
- 禁止艺术字体、手写体、圆体
- 禁止文字描边、粗体阴影
- 禁止两端对齐（justify）
- 禁止信息过满、留白不足

### 12.4 动效禁忌
- 禁止弹性/回弹/弹跳缓动
- 禁止无限旋转加载动画
- 禁止 3D 翻转、翻页、立方体转场
- 禁止快速闪烁（>3Hz，光敏性安全）
- 禁止鼠标跟随特效、粒子拖尾

### 12.5 元素禁忌
- 禁止卡通装饰元素（星星、爱心、表情符号）
- 禁止拟物化 3D 按钮、立体开关
- 禁止表情符号（emoji）作为界面元素
- 禁止广告位式横幅、闪烁促销标签
- 禁止社交 App 式的红点消息气泡（用数字角标代替）

---

> 本规范为明日方舟 UI 设计的完整执行标准。设计时应逐条对照，任何偏离都需有明确的功能理由。最终目标是让界面看起来像「罗德岛终端系统的原生界面」，而不是「套了明日方舟皮肤的普通 App」。
