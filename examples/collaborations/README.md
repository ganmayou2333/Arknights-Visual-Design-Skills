# 真实联动示例（Real Collaboration Examples）

本目录收录三张按 **poster-style.md 第 9 章「联名海报适配规范」** 生成的《明日方舟》真实联动主视觉示例，用于演示联名设计的落地方法：

> **核心原则**：方舟角色保持原画风不变，背景替换为对方 IP 的经典场景，前景融入对方标志性道具，视觉权重约 6:4；全画面统一低饱和主色调 + 10%–15% 胶片颗粒 + 10%–20% 暗角，点睛亮色 ≤5%。

---

## 01 · 明日方舟 × 彩虹六号：围攻「源石尘行动」

![源石尘行动](01-arknights-x-r6s-source-dust-operation.jpg)

**联动背景**：2021 年 3 月开启的 SideStory（2024 年 3 月复刻），联动干员为灰烬、霜华、闪击、战车，是最具代表性的军事射击类联动。

**设计要点（对应规范）**：
- 角色：方舟立绘风格战术女干员，姿态沉稳持枪侧对镜头（构图 §2.1）
- 背景：萨尔贡荒漠小镇废墟、沙尘、铁丝网（联名类型适配 §9.3 军事/射击类）
- 前景：钢盔、步枪剪影、飘散硝烟，浅景深虚化（前景层 §2.2）
- 色调：军绿 + 土黄 + 冷灰统一主色调，暗部保留细节（色彩体系 §3）
- 文字：顶部双方标识并列（"ARKNIGHTS" / "RAINBOW SIX SIEGE"），底部活动名（文字与标识 §7）

## 02 · 明日方舟 × 迷宫饭「泰拉饭」

![泰拉饭](02-arknights-x-delicious-in-dungeon-terra-meal.jpg)

**联动背景**：2024 年 9 月（国服）开启的 SideStory，联动干员为玛露西尔、莱欧斯、齐尔查克、森西，代表动漫/游戏类联动。

**设计要点（对应规范）**：
- 角色：方舟画风冒险者（银发半精灵术师 + 铠甲战士），不做对方画风转换（联名禁忌 §9.4）
- 背景：地下城迷宫石廊、烛光与魔法微光（动漫/游戏类联动 §9.3）
- 前景：地图册、铁锅与魔物食材、魔法微光
- 色调：原作明亮奇幻配色降饱和 40%–60% 后作为主色调，保持方舟冷峻基底（联名类型适配）
- 文字：顶部双方标识并列，底部活动名"泰拉饭"

## 03 · 明日方舟 × 怪物猎人「落叶逐火」

![落叶逐火](03-arknights-x-monster-hunter-falling-leaves.jpg)

**联动背景**：2023 年 3 月 7 日开启的 SideStory，联动干员为麒麟X夜刀、火龙S黑角与泰拉大陆调查团（艾露猫），是狩猎冒险类联动的代表。

**设计要点（对应规范）**：
- 角色：方舟画风猎装干员，持太刀凝视远方龙影（姿态推荐 §2.1.2）
- 背景：深秋山林荒野、远处龙种剪影、暮色（环境类型库 §6.1）
- 前景：龙鳞碎片、羽毛、篝火余烬火星
- 色调：暗红 + 深灰 + 土黄低饱和主色调，颗粒 15%、暗角 18%（颗粒与做旧 §8）
- 文字：顶部双方标识并列，底部活动名"落叶逐火"

可直接将本目录图片作为联名设计的**风格参考（moodboard）**，或将各节的提示词思路应用到你的生成流程中：先确定联动类型（军事/品牌/动漫游戏）→ 按 §9.3 适配背景与前景 → 统一降饱和色调 → 叠加颗粒与暗角 → 布置双方标识信息区。
