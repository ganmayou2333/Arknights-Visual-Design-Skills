# Arknights Image Style（明日方舟静态生图风格）

## Overview

本技能提供一套严格对齐《明日方舟》美术风格的**静态图片**视觉规范，面向海报/主视觉（KV）/角色立绘/IP 联名宣传图等平面产物的生成与评估。目标是让产出具备统一的"舟味"：克制、冷峻、战术终端感、末世叙事感。

所有量化参数（色值、占比、透明度、字号、切角、颗粒）均可直接套用，无需猜测。

## 核心设计总则

1. **视觉定位**：海报是「末世战场纪实摄影 + 军事档案宣传画」的混合体，像一张从罗德岛档案库取出的战地记录照片——有叙事、有重量、有沉默的张力
2. **色彩底层逻辑**：低饱和冷灰/深暗基底 + 单一主色调，仅 1–2 处高饱和点睛色（≤5%），拒绝大面积艳丽
3. **质感统一**：哑光 + 胶片颗粒/做旧，柔和侧光体积感，暗部不死黑（保留 5%–10% 亮度）
4. **字体统一**：思源黑体（标题 Heavy、正文 Normal、注释 Light），纯色无渐变
5. **角色表现**：写实化比例（7–7.5 头身）、克制表情、姿态沉稳、战术化装备
6. **功能性优先**：文字信息区不覆盖角色主体，装饰即信息

## 使用流程

### A. 生图模式
1. **读取规范**：读取 `references/poster-style.md`（构图/色彩/光影/角色/背景/文字/颗粒/联名适配/配方/尺寸/禁忌）
2. **明确品类**：是活动主视觉 KV、角色立绘、IP 联名宣传图、周年贺图还是节日物料——对应配方章节
3. **执行**：按规范生成，量化参数直接套用（角色占比 55%–70%、点睛 ≤5%、颗粒 10%–15%、暗角 10%–20%）
4. **自检**：对照 `poster-style.md` 末尾"海报禁忌清单"逐条检查，命中任何一条即修正

### B. 评估模式（对已有图片打分）
对任意待评估的方舟风格图片，沿以下维度 0–10 分打分，并用**禁忌否决制**（命中海报禁忌清单任意一条 → 直接判不合格）：

| 评估维度 | 检查要点（满分 10） |
|---|---|
| 调性还原 | 纪实、沉静、叙事、冷峻、末世感是否到位 |
| 色彩规范 | 低饱和冷灰基底、单主色调、点睛 ≤5%、暗部不死黑、无高饱和原色 |
| 构图 | 角色 55%–70%、前中后三层景深、偏移构图（非满幅居中）、不在关节处裁切 |
| 光影质感 | 柔和侧光体积感、哑光 + 颗粒/做旧、无卡通赛璐璐平涂 |
| 角色表现 | 写实比例、克制表情、沉稳姿态、战术化装备、无 Q 版化 |
| 文字排版 | 思源黑体分级字重、纯色无渐变、信息区不遮主体、无艺术/发光字 |

**评估输出**：总分（满分 60）+ 各维度分 + 命中的禁忌项 + 一句话改进建议。

## 快速要点（含关键量化参数）

- **主体**：角色占 55%–70%（半身/七分），全身立绘 80%–90%；重心在画面上 1/3–1/2，三分法偏移构图
- **色调**：先定单一主色调（战地=军绿土黄、剧情=蓝灰暗青、炎国=低饱和朱砂、周年=暗金深蓝），90% 以上颜色落在此色系
- **点睛色**：源石蓝 `#56B6C9`、指示灯橙 `#E08E45`、瞳孔高光、阵营色、暗红；总面积 ≤5%
- **光影**：侧光/侧逆光主光，主光:环境光 2:1–4:1，轮廓光 1–3px 亮边
- **质感**：颗粒 10%–15%、划痕 3%–8%（≤5–8 处）、暗角 10%–20%、曝光 EV -0.3 至 -0.7
- **文字**：思源黑体 Heavy 标题（中文字距 -0.02em、英文全大写 +0.05em），副标题 Light
- **联名**：方舟角色保持原画风，背景/前景融入对方 IP 标志物，视觉权重 6:4
- 详细规范 → `references/poster-style.md`

## 通用禁忌

- 禁止高饱和平涂卡通风、彩虹渐变、红蓝撞色、大面积萌系粉色/紫色
- 禁止角色居中+正面+满幅（大头照式）、关节处裁切
- 禁止夸张表情、卖萌姿势、偶像化姿势、Q 版化
- 禁止艺术字体、渐变文字、发光文字、描边文字
- 禁止过度磨皮、镜面高光、镜头光晕滥用、颗粒 >20%
