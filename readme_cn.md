## 简介

本技能将通用 AI 代理转变为明日方舟风格的设计专家。其中包含**可直接套用的量化参数**——色值、字重、间距、动画时长、透明度——让生成的 UI、海报、动画始终具备统一且可识别的"舟味"：克制、冷峻、战术终端感、末世叙事感。

无论你需要生成游戏 UI 原型、角色主视觉、IP 联名海报、PV 分镜，还是 Live2D 动态规范，本技能都提供完整的执行标准。

## 功能特性

### 三份完整风格手册

| 品类 | 参考文件 | 内容覆盖 |
|------|---------|---------|
| **UI 界面** | `references/ui-style.md` | 12 章：色彩系统、字体排版、布局网格、组件规范、图标语言、背景纹理、动效规范、典型界面配方、交互反馈、数据可视化、禁忌清单 |
| **海报/主视觉** | `references/poster-style.md` | 12 章：构图系统、色彩体系、光影质感、角色表现、背景环境、文字标识、颗粒做旧、联名适配、典型配方、尺寸输出、禁忌清单 |
| **动画/动态** | `references/animation-style.md` | 12 章：节奏剪辑、镜头语言、角色动画、环境特效、UI 转场、技能演出、声音设计、Live2D 规范、典型配方、技术规格、禁忌清单 |

### 全量化参数

所有规范均包含具体数值：
- 精确十六进制色值（`#1A1C20`、`#3F72AF`、`#56B6C9` 等）
- 字体字重与字间距数值
- 间距阶梯（4px 基础单位）
- 动画时长与缓动函数
- 纹理和叠加层的透明度百分比
- 组件尺寸与切角大小

### 通用禁忌清单

每份参考文件末尾均附有详细的禁忌清单，防止常见风格偏差（如圆角卡片、彩虹渐变、弹性动效、Q 版表情等）。

## 安装教程

### 方式一：手动安装

手动安装是最可靠的方式，确保所有文件内容完整准确。

#### 步骤 1：获取技能文件

- **如果从 GitHub 下载：** 点击仓库主页的 `Code` 按钮 → `Download ZIP`，下载后解压到本地。
- **如果使用 Git 克隆：**
  ```bash
  git clone https://github.com/ganmayou2333/avs.git
  ```

#### 步骤 2：定位技能目录

找到你的 AI 代理（Agent）的技能安装目录。不同运行环境的路径不同，常见位置包括：

| 运行环境 | 典型路径 |
|---------|---------|
| 豆包 / Super Doubao | `~/.super_doubao/super-doubao-runtime/workspace/.user_skills/` |
| GitHub Copilot | `~/.codex/skills/` |
| Claude / 其他 Agent | `~/.agents/skills/` |
| 自定义配置 | 你在 AI 代理设置中指定的技能根目录 |

> **提示：** 如果你不确定路径，可以在 AI 代理中询问："我的技能目录在哪里？"或查看代理的设置/文档。

#### 步骤 3：复制技能文件夹

将整个 `arknights-design-style-guide/` 文件夹复制到技能目录中：

```bash
# Linux / macOS
cp -r arknights-design-style-guide ~/.super_doubao/super-doubao-runtime/workspace/.user_skills/

# Windows (PowerShell)
Copy-Item -Recurse .\arknights-design-style-guide "$env:USERPROFILE\.super_doubao\super-doubao-runtime\workspace\.user_skills\"
```

#### 步骤 4：验证文件结构

确保复制后的目录结构完整：

```
arknights-design-style-guide/
├── SKILL.md
├── README.md
├── readme_cn.md
├── LICENSE
└── references/
    ├── ui-style.md
    ├── poster-style.md
    └── animation-style.md
```

可以用以下命令验证：

```bash
ls -la ~/.super_doubao/super-doubao-runtime/workspace/.user_skills/arknights-design-style-guide/
ls -la ~/.super_doubao/super-doubao-runtime/workspace/.user_skills/arknights-design-style-guide/references/
```

#### 步骤 5：重启/重载 AI 代理

重启你的 AI 代理会话，或触发技能目录重新扫描，使代理识别新安装的技能。

#### 步骤 6：测试安装

向 AI 代理发送测试指令，例如：
- "帮我设计一个明日方舟风格的干员档案界面"
- "生成一张明日方舟风格的活动主视觉海报"
- "明日方舟风格的 PV 动画有什么规范？"

如果代理自动加载了本技能并按照规范回答，说明安装成功。

### 方式二：AI 提示词安装

如果你的 AI 代理支持通过自然语言创建技能，可以直接向代理发送以下提示词，让它自动生成完整的技能文件。

#### 安装提示词（复制以下全部内容）

```
请在我的用户技能目录（.user_skills）中创建一个名为 "arknights-design-style-guide" 的新技能。

这个技能提供《明日方舟》官方美术风格的完整视觉设计规范，覆盖三大品类：UI 界面、海报/主视觉、动画/动态设计。

技能必须包含以下文件：

1. SKILL.md — 主入口文件，包含：
   - YAML frontmatter（name: arknights-design-style-guide，description 需详细描述触发场景，包括"舟味"、"鹰角风格"、"方舟美术"、"Arknights style"等关键词）
   - 核心设计总则（6 条通用原则）
   - 使用工作流程（判断品类→读取分册→执行→自检）
   - 三品类快速要点
   - 通用禁忌清单
   - 引用 references/ 下的三个文件

2. references/ui-style.md — UI 设计完整规范，包含 12 章：
   - 核心设计哲学、色彩系统（深炭灰 #1A1C20 基底、罗德岛蓝 #3F72AF 主色、荧光青/暗橙/暗红功能色、文字色阶）
   - 字体排版（思源黑体、Heavy/Normal/Light 字重、字距规范、左对齐）
   - 布局网格（12 列、45° 斜切角、4px 间距阶梯）
   - 组件规范（按钮、输入框、标签、列表、进度条、弹窗、Tab、开关）
   - 图标语言（线性 1.5px、技能图标、阵营徽记）
   - 背景纹理（噪点 3-5%、暗纹 5-10%、网格底纹）
   - UI 动效（150-300ms、linear/ease-out、禁止弹性、故障闪烁特效）
   - 典型界面配方（主界面、干员档案、作战界面、招募界面、活动页、加载页）
   - 交互反馈、数据可视化、禁忌清单

3. references/poster-style.md — 海报设计完整规范，包含 12 章：
   - 核心设计哲学（纪实战术海报定位）
   - 构图系统（角色占比 55-70%、三分法、前中后三层景深、信息区布局）
   - 色彩体系（主色调确定原则、点睛色 ≤5%、单色相/类似色配色）
   - 光影质感（主光/辅光/轮廓光、明暗分布、皮肤/服装/源石质感）
   - 角色表现（7-7.5 头身、克制表情、发型配饰、武器道具）
   - 背景环境（环境类型库、大气透视、细节递减、叙事元素）
   - 文字标识（标题 Heavy 倾斜 5-8°、副标题 Light、Logo 规范、编号档案元素）
   - 颗粒做旧（10-15% 胶片颗粒、划痕磨损、色彩偏移、暗角）
   - 联名适配（方舟角色 6 成/对方元素 4 成、军事/品牌/动漫联动类型）
   - 典型配方（活动 KV、战地联名、角色立绘、周年贺图、节日图）
   - 尺寸输出、禁忌清单

4. references/animation-style.md — 动画设计完整规范，包含 12 章：
   - 核心设计哲学（末世战争纪录片定位）
   - 节奏剪辑（静-动-静曲线、单镜头 ≥2 秒、快切 ≤10%、剪辑原则）
   - 镜头语言（中景 35%/近景 25%/远景 20%、固定镜头 40%、慢推 25%、平视为主）
   - 角色动画（常态呼吸/眨眼/衣物飘动、战斗三段式蓄力-1-2帧停顿-跟随、微表情规范）
   - 环境特效（尘埃/扬尘/灯光/粒子、源石技能冷色调、爆炸三段式、枪口火光、天气系统）
   - UI 转场（边缘滑入/扫描线/故障花屏入场、黑场淡入淡出/烟雾/扫描线/故障闪切转场）
   - 技能演出（四阶段蓄力-释放-命中-余波、近战/远程/治疗/召唤类型适配）
   - 声音设计（四层声音结构、环境音、动作音、源石音效、BGM、语音）
   - Live2D 规范（8-12 秒循环、基础动态层、交互动作）
   - 典型配方（宣传 PV、技能演示、剧情过场、界面演示）
   - 技术规格、禁忌清单

所有内容使用中文撰写。所有参数必须量化（色值用十六进制、尺寸用 px、时长用秒/毫秒、透明度用百分比）。每份参考文件末尾必须有详细的禁忌清单。
```

#### 使用方法

1. 打开你的 AI 代理对话窗口
2. 将上面的提示词完整复制粘贴发送
3. 等待代理生成技能文件（可能需要 1–3 分钟）
4. 生成完成后，验证文件结构是否完整
5. 重启或重载代理会话

- 提示词安装依赖于代理的技能创建能力，不同代理的支持程度不同
- 生成的内容可能与标准版本有细微差异，建议对照本仓库的文件进行核对

## 使用方法

安装完成后，当用户请求匹配技能的触发描述时，技能会自动激活。代理将：

1. **判断品类** — 确定任务属于 UI、海报还是动画（复合任务同时加载多个参考）
2. **读取对应分册** — 遵循渐进式加载原则，仅加载相关参考文件
3. **套用量化参数** — 直接使用色值、字体规范、间距、时长等数值
4. **对照禁忌自检** — 检查是否存在禁忌元素（圆角、彩虹渐变、弹性动效等）

## 设计哲学

所有明日方舟视觉设计的核心比喻：**想象你是一名随军纪录片摄影师，在泰拉大陆的战场上记录一切。** 你不修饰、不煽情，只是冷静地拍摄。偶尔，一个瞬间让你屏住呼吸。

这转化为六条通用原则：

1. **克制** — 低饱和暗基底，仅 1–2 处点睛色，绝不花哨
2. **冷峻** — 冷灰色调、硬朗几何、无柔软圆角
3. **战术终端感** — 每个元素都像罗德岛指挥终端的一部分
4. **末世叙事感** — 废墟、沙尘、做旧纹理、沉重氛围
5. **功能优先于装饰** — 元素无信息功能则删除
6. **纪实写实感** — 胶片颗粒、自然光影、不完美构图
